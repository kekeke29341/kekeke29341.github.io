ARTEX / LOCAL LLM PENTEST

ローカルLLMで動く、
自律型ペネトレーションテスト基盤。

ARTEX は、LLM マルチエージェントが目標を分解し、実ツールを実行し、資産と脆弱性をグラフに積み上げるシステムです。 中野哲平が趣味で開発と拡張を続けています。ツールが欲しい方は、下のフォームから問い合わせてください。

ツールについて問い合わせる 画面を見る

商用のセキュリティ診断サービスではありません。所有環境、または書面で許可を得た対象での利用を前提とします。

なにを作っているか

中国発のオープンソース ARTEX をベースにしたグローバル版の開発・拡張です。Go の単一バイナリに Next.js フロントエンドを埋め込み、データは PostgreSQL に保存します。

マルチエージェント実行

目標分解・計画・実行・再検証のエージェントが、許可された範囲でツールを動かし、検出結果を蓄積します。

ローカルLLM対応

フロンティアモデルだけでなく、OpenAI互換エンドポイント経由でローカルLLMにも接続できます。

多言語の出力

英語を既定にし、日本語・韓国語・中国語・スペイン語へ切替。レポート・要約・チャットの表示言語を揃えます。

人が途中で介入できる

実行中にチャットでヒントを入れ、攻撃チェーンの要約を確認しながら進められます。

Go Next.js PostgreSQL Docker Compose OpenAI-compatible LLM

いま手がけている拡張

グローバル版としての整備を続けています。エージェントの内部推論プロンプトは性能維持のため原語のままにし、ユーザー向け出力だけを選択言語に揃えています。

言語とドキュメント

UI メッセージ、日付ロケール、設定画面、README の日本語を含む多言語スタックの更新。

ローカル運用

隔離されたローカル環境での起動、LLM 接続、スキルとデータの永続化。

検出結果とレポート

深刻度・資産・タスクごとの集計、CSV 出力、活動フィードの見え方の改善。

防御側の読み方

自律型 AI 攻撃を理解し、検知・遮断の材料として読むための整理。無許可利用は対象外です。

画面

データはローカルに隔離したサンドボックスのものです。標的は架空のドメインとプライベートアドレス帯です。

利用範囲：所有する環境、または明示的な書面許可がある対象に限って使ってください。無許可のスキャン・侵入・データ持ち出しは犯罪になります。学習・研究・隔離されたローカル環境での検証を前提とします。
