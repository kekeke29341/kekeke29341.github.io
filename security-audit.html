使い方（配布後の流れ）

メールで受け取った一式を、隔離されたローカル環境で動かします。許可のない外部資産には向けないでください。

  1. 1. 環境を用意する Docker と Docker Compose を入れます。PostgreSQL は compose が起動します。LLM 用の API キー、またはローカルの OpenAI互換エンドポイントを用意します。
  2. 2. 起動する 配布物の手順どおりに `.env` を用意し、`docker compose up -d` で起動します。ブラウザで管理画面を開き、初回の管理者パスワードを設定します。
  3. 3. LLM を接続する 設定画面でプロバイダとモデルを指定します。ローカルLLMの場合は OpenAI互換のベース URL とモデル名を入れます。
  4. 4. 対象と許可範囲を決める 所有する検証環境、または書面で許可を得た対象だけを登録します。除外対象と停止条件も先に決めます。
  5. 5. タスクを実行する 目標を書いてエージェントを走らせます。進行中はダッシュボードと活動フィードで状況を見ます。必要ならチャットで指示を追加します。
  6. 6. 結果を確認する 検出結果を深刻度と資産ごとに確認し、CSV に出力します。修正後の再検証も同じ画面から進められます。

利用範囲：所有する環境、または明示的な書面許可がある対象に限って使ってください。無許可のスキャン・侵入・データ持ち出しは犯罪になります。学習・研究・隔離されたローカル環境での検証を前提とします。
